### **Color Usage Rules**

✅ **DO:**
- Primary color (Cyan) on 60-70% of branded materials
- Use dark backgrounds with light text
- Cyan + Purple for premium tech messaging
- Gold for exclusive/premium features
- Respect 3:1 minimum contrast ratio

❌ **DON'T:**
- Mix more than 2 accent colors in single design
- Use bright backgrounds with dark text (except minimal use)
- Apply gradients indiscriminately
- Use colors from competitor palettes
- Break contrast rules for aesthetics

## 🔤 TYPOGRAPHY

### **Font Pairing**

**Primary (Headers, Brand Voice):**
```
Font: Georgia
Weights: Regular, Bold, Italic
Sizes: 28pt-72pt (headers), 16pt-20pt (subheaders)
Usage: Logo, main headers, premium messaging
Personality: Elegant, trustworthy, timeless
```

**Secondary (Body, UI):**
```
Font: Calibri
Weights: Regular, Light, Bold
Sizes: 11pt-16pt (body), 12pt-14pt (UI)
Usage: Paragraphs, interface, supporting text
Personality: Clean, modern, professional
```

### **Typographic Hierarchy**

| Level | Size | Weight | Color | Use |
|-------|------|--------|-------|-----|
| **H1** | 44-66pt | Georgia Bold | Cyan | Page titles, hero sections |
| **H2** | 28-36pt | Georgia Bold | Cyan/Gold | Section headers |
| **H3** | 18-24pt | Georgia Bold | Electric/Purple | Subheaders |
| **Body** | 14-16pt | Calibri Regular | Silver | Main text |
| **Caption** | 11-12pt | Calibri Light | Silver (60% opacity) | Supporting info |
| **Accent** | Varies | Georgia Italic | Gold | Callouts, premium notes |

### **Line Height & Spacing**
- **Headers:** 1.2 line height
- **Body:** 1.6 line height (premium, readable)
- **Paragraph gaps:** 12-16px
- **Letter spacing:** 0 (normal), +0.5px for headers (luxury feel)

## 🏗️ LOGO SYSTEM

### **Primary Logo**
- **Use:** Most branded contexts
- **Style:** Full hexagon + quantum particle + energy waves
- **Colors:** Cyan electric, optional secondary accent
- **Minimum size:** 128px
- **Clear space:** 25px minimum all sides

### **Icon / Glyph**
- **Use:** Profile pictures, favicons, tight UI
- **Style:** Central particle + 1-2 orbit lines only
- **Colors:** Cyan monochrome preferred
- **Minimum size:** 32px
- **Application:** Twitter, Instagram profile, tab icon

### **Horizontal Lockup**
- **Use:** Social media covers, wide banners
- **Style:** Logo left, "QUANTFLOW" right (Georgia Bold, Cyan)
- **Spacing:** Logo width × 0.5 gap
- **Height:** Keep consistent aspect ratio

### **Monochrome Version**
- **Use:** When color restricted (b/w printing, single color)
- **Style:** Hexagon + particle in solid color
- **Colors:** Either white on dark or dark on white
- **Contrast:** Ensure 3:1+ ratio

## 🎬 MOTION & ANIMATION

### **Logo Animation**
```
Particle Orbit:
- Duration: 4-5 seconds
- Direction: Clockwise, smooth easing
- Effect: Very subtle (10-15° rotation range)
- Use: Website hero, loading states

Wave Pulse:
- Duration: 2-3 seconds
- Effect: Opacity 70% ↔ 100%
- Use: Create life without distraction
```

### **UI Animations**
```
Button Hover: Subtle grow (105%) + opacity shift (100% → 110%)
Link Hover: Underline + color shift (Cyan → Gold)
Loading: Subtle fade pulse (0.8s loop)
Transition: Smooth easing (0.3-0.4s)
```

### **Writing Style**

**Characteristics:**
- **Confident but not arrogant** — "We see what others miss" not "We're the best"
- **Technical but accessible** — Explain complexity clearly
- **Premium but honest** — No hype, just results
- **Future-focused** — Innovation, beta, "coming soon" language

✅ **Use:**
- "Institutional-grade"
- "Real-time liquidity flows"
- "Quantum-powered analytics"
- "Sophisticated traders"

- "Building the next..."

## ❓ BRAND FAQ

**Q: Can we use RGB instead of Hex?**  
A: Yes, but Hex is primary. Always include both for color accuracy.

**Q: What if we need a light background?**  
A: Use dark text (dark mode preferred). If light background required:
- Logo: Dark version or monochrome
- Text: Dark (#0F1419) on light background
- Buttons: Cyan border, dark text

**Q: Can we animate the logo?**  
A: Yes, but keep it subtle. See Motion & Animation section.

**Q: What about variations for different contexts?**  
A: Approved variations: Icon/Glyph, Monochrome, Horizontal Lockup. No unauthorized variations.

**Q: How often should we refresh the brand?**  
A: Every 3-5 years minimum. Check for relevance in crypto/fintech space annually.
